1. Overview

What is this module?

The Amazon S3 Connector integrates Odoo with AWS S3 for seamless file storage and management. It auto-uploads attachments from Contacts, Tasks, and Planning Roles daily, with a built-in dashboard for browsing, previewing, and downloading files.


Key Features

📊
S3 Files Dashboard
Browse all S3 bucket files in List View or Kanban (Grid) View directly inside Odoo.
⬆️
Manual File Upload
Upload any file to your S3 bucket from Odoo — no AWS Console login needed.
⏰
Scheduled Auto-Upload
Daily auto-upload of attachments from Contacts, Tasks & Planning Roles.
🔍
Search, Filter & Sort
Live search, filter by file type (PDF, Image, ZIP, XLSX), and sort by name or date.
👁️
Inline Preview Panel
Preview images and PDFs instantly inside the dashboard — no download needed.
🔐
Secure Credential Storage
AWS keys stored as encrypted Odoo system parameters. Auto-cleaned on uninstall.

3. AWS Credentials

Step-by-Step Guide

How to get your Access Key, Secret Key, and Bucket Name from AWS Console.

3.1 What You Need

CredentialDescription
Access Key IDA 20-character alphanumeric string identifying your IAM user. Example: AKIAIOSFODNN7EXAMPLE
Secret Access KeyA 40-character private key paired with the Access Key ID. Shown only once — save it immediately.
Bucket NameThe exact name of your S3 bucket as created in AWS. Example: my-company-odoo-files

3.2 How to Generate Your Access Keys

Log in to AWS Management Console at console.aws.amazon.com and follow these steps:

STEP 1 — Open IAM and go to the Security Credentials tab

In the AWS Console search bar, type IAM and open it. In the left sidebar click Users, then click your IAM user's name. Select the Security credentials tab, and click the Create access key button.

Fig 1 — IAM User page: Security credentials tab → Create access key button

STEP 2 — Select Use Case: 'Other'

AWS will ask you to select a use case for the key. Select Other from the list, then click Next. You may optionally add a description tag, then click Create access key.

Fig 2 — Select 'Other' as the use case, then click Next

STEP 3 — Copy or Download Your Keys

AWS will display your Access Key ID and Secret Access Key. Copy both immediately or click Download .csv file. You will NOT be able to view the Secret Access Key again after closing this dialog.

Fig 3 — Copy both keys or download the .csv file before closing
⚠️ Important: The Secret Access Key is shown only once by AWS. If you lose it, you must delete the key pair and create a new one.
4. Installation

Install the Module

1

Install Python Dependency

On your Odoo server run: pip install boto3

2

Install from Odoo Apps

Search for Amazon S3 Connector in Odoo Apps and click Install.

5. Configuration

Configuration in Odoo Settings

Three fields to fill in — that's all.

1

Go to Settings → Integrations

In Odoo top menu, go to Settings and scroll down to the Integrations section.

2

Enable Amazon S3 Cloud Storage

Toggle on Amazon S3 Cloud Storage to reveal the credential fields.

3

Fill in your AWS credentials

FieldValue
Access KeyYour IAM user Access Key ID from AWS
Secret Access KeyYour IAM user Secret Access Key from AWS
Bucket NameThe exact name of your S3 bucket (case-sensitive)
4

Click Save

Credentials are stored as secure system parameters in Odoo.

Fig — Amazon S3 Cloud Storage configuration in Odoo Settings (Integrations section)
6. Using the Module

Dashboard & Features

6.1 Amazon S3 Dashboard

After saving settings, a new top-level menu item Amazon S3 Dashboard will appear. The dashboard supports two views:

📋
List View
Detailed tabular layout showing file name, type, size, and last modified date. Best for managing many files.
⊞
Kanban (Grid) View
Visual card-based layout with file icons and image thumbnails. Best for browsing media files.

6.2 Manual File Upload

1

Click Upload button

Top-right corner of the dashboard.

2

Select your file

Choose any file from your computer in the dialog.

3

Click Upload & Refresh

A success notification confirms the upload. Click Refresh to see the new file.

6.3 Automatic Scheduled Upload

⏰

Amazon S3 — Daily Auto Upload

A built-in Scheduled Action runs every day at 23:55 server time. It scans for new attachments (last 24 hours) on Contacts, Project Tasks, and Planning Roles — uploads them to S3, posts a chatter note on each record, and marks the attachment as uploaded to prevent duplicates.

📂 Contacts ✅ Project Tasks 📅 Planning Roles 🔁 No Duplicates 💬 Chatter Note
